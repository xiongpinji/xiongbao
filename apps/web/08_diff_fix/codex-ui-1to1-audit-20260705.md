## 与 Codex 当前可见 UI 的结构差异

### 1. 左侧导航

Codex：
- 左侧是会话列表优先。
- 顶部只有 `新对话`、`搜索` 等基础动作。
- 分组、时间、选中态都很克制。
- 底部用户信息和设置入口很轻。

当前前端：
- 有独立窄 Rail、品牌大 Logo、任务看板、固定项目卡。
- 金色主按钮和任务状态更像产品工作台，不是 Codex 会话列表。

结论：需要重构为会话列表优先，但保留熊宝品牌标识和金色新建入口。

### 2. 中央主区域

Codex：
- 默认是简洁对话流。
- 输入框是核心视觉焦点。

当前前端：
- `/chat` 中央有熊宝大图、强金色品牌字、较大的英雄区域。
- 这是 Panda Agent 的品牌核心，按用户要求保留。

结论：熊宝英雄区不是缺陷；后续只优化它与 composer、会话流的比例关系。

### 3. 输入框

Codex：
- 输入框收敛、低边界、底部控制行清晰。
- 附件、权限、模型、语音、发送按钮在同一操作带内。

当前前端：
- 输入框更大，视觉更厚。
- 快捷按钮和推荐动作在输入框下方铺开。
- 金色发送按钮更强品牌化。

结论：需要统一为 Codex 风格 composer，但发送按钮和焦点态可保留金色品牌。

### 4. 右侧上下文

Codex：
- 右侧上下文更克制，可隐藏。
- 信息层级偏当前会话和相关上下文。

当前前端：
- 右侧 Context 里有多个产品卡片和上下文助手。
- 信息密度和产品入口更多。

结论：1:1 时需要减少卡片感，改成会话上下文面板。

### 5. 色彩与材质

Codex：
- 主色是黑、深灰、白、低饱和边界。
- Accent 只用于状态和必要动作。

当前前端：
- 金色、琥珀色、品牌光效占比高。
- 更接近高端游戏/Agent 品牌台。

结论：金色保留为品牌主视觉，但在导航、右侧上下文和普通卡片中降低发光与面积占比。

### 6. 设置页

Codex：
- 设置是独立页面，左侧设置目录，右侧设置详情。

当前前端：
- `/settings` 仍在主 AppShell 结构中。

结论：需要让设置脱离主工作台壳，改成 Codex 设置页结构。

## 结构复刻执行标准

1. 默认 `/chat` 必须是会话流 + composer + 熊宝品牌英雄区；熊宝大图保留。
2. 左侧必须以会话列表为主体，任务看板降级或移到工作区入口。
3. 右侧 Context 默认为折叠或轻量上下文，不放大型产品卡片。
4. 全局颜色收敛到 Codex 中性暗色；金色用于品牌、主操作、焦点态和少量状态。
5. 设置页单独全屏，不被主工作台左右栏包裹。
6. 短剧工厂继续保留独立无限画布，但工具栏、面板、节点库改成 Codex 低边界风格。
7. 所有页面通过 390、768、1280、1728 宽度检查，无横向溢出。
