行业/场景交付变体包指南（P3 商业复制）

用途：把标准交付物按行业/场景做变体复制时，明确"改什么、不改什么"。

1. 变体制作的固定动作

  1. 复制 docs/delivery-templates/ 全套模板，建立 <行业>-deliverables/ 目录
  2. 按下表逐项裁剪
  3. 变体版的任何口径降级（如更高的安全默认值）必须反向检查是否可回馈主线

2. 裁剪矩阵

维度 可定制 不可动
LLM 路径 provider 选择、模型档位、代理拓扑 密钥注入方式（必须 secretRef/secret manager）
安全默认值 只能更严（更短 token TTL、更严限流） require_auth=true、shell/python 默认禁用、沙箱 fail-closed
技能库 行业技能包（skills 目录预置） 技能质量门禁逻辑
工作流/模板 行业工作流模板、短剧模板等行业内容 模板引擎与 API 形状
口径文案 行业化产品名/文案/案例 SOT 状态口径（GA 边界、不可宣称项）
合规 行业特有审计/保留要求（加长只能） 审计事件覆盖范围（不得裁剪）

3. 已识别变体候选

变体 差异要点 状态
短剧/内容工厂 creative-studio 域、媒体 provider 链、行业技能包 ⏸️ 已暂停（owner 决策 2026-08-04），待整体移植完成后重启
研发效能（Codex 对标） code_review、AGENTS.md 分层指令、权限模式 ✅ 变体包 v1 已建立（variants/dev-effectiveness/：裁剪决策 + 口径页 + 演示脚本）— 2026-08-04
企业内部助手 SSO/OIDC 必配、审计保留加长、知识库预置 ✅ 变体包 v1 已建立（variants/enterprise-assistant/：裁剪决策 + 口径页 + 演示脚本）— 2026-08-04

4. 变体验收

  • [ ] 主线路径回归不受影响（变体只增不改时跑主线门禁即可）
  • [ ] 变体特有项有独立证据（如行业技能包命中率抽验）
  • [ ] 变体口径页已按 SOT 不可宣称项核对
