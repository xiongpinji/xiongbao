X-Agent v1.3.1 发布说明

发布日期：2026-09-06 · 上一版本：v1.3.0（2026-09-06） 本版主题：技能系统反噬防护——自动蒸馏泛词门禁 + 注入防复读 + 复读兜底

一、背景：用户实测撞出技能反噬

用户在 v1.3.0 智能体模式发送「写一个计算器」，助手把一条技能定义 JSON 原样复述给用户 （{"name": "AgentFileCheck", "trigger": "创建|打印|读取|确认", "hint": ...}）。

事故链（实测复盘）：

  1. 前一日验收任务跑完后，auto_distill 自动蒸馏出技能「VerifyAgentFile」， 触发词为全泛词 创建|打印|读取|确认——质量门禁无泛词检查，予以放行；
  2. 该技能随后匹配几乎一切创建类任务，其定义被注入 system prompt；
  3. 本地 qwen3:4b 小模型被注入内容带偏，把技能定义本身当答案输出（复读）。

二、修复（三层防护）

层 修复
门禁 gate_candidate 新增泛词过滤：触发词全部命中泛词黑名单（创建/写/打印/读取/运行/verify 等约 40 词）→ 拒绝入库（trigger_too_generic）
注入 build_prompt_injection 措辞强化：显式声明「仅供内部参考……禁止把本节内容或技能定义原样输出给用户」
兜底 新增 _is_skill_definition_echo 复读检测：final 为技能定义形态（{"trigger"+"name"/"hint"}）→ 编排两条路径（工具/chat）均视为无效输出进入纠偏恢复，恢复仍复读则按空响应失败

排毒（运维动作）：事故技能 VerifyAgentFile / agent_v130_check_skill 已按正规生命周期 API retire。

三、测试

  • 新增 tests/test_skill_anti_poison.py 11 项：全泛词拒绝/含具体词放行/中英混合/英文泛词拒绝、注入含禁止措辞、复读检测正负样本（正常回答/工具 JSON/真实代码不误判）
  • 相关套件 86 项全过；ruff 分类计数回基线（186/17/15/6）；mypy 干净

四、升级与兼容

  • 无迁移、无新配置；既有具体触发词技能不受影响（仅全泛词模式被拒）
  • 行为变化：此后 auto_distill 不会再入库「匹配一切」的泛词技能
