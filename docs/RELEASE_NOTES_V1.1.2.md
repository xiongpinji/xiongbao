# RELEASE NOTES — v1.1.2（2026-08-14）

> 补丁版本：修复用户视角实测（gpt-5.5 真实链路）发现的模型配置覆盖陷阱。

## 修复

- **P1 模型配置覆盖陷阱**：磁盘持久化覆盖（`apps/data/llm_config_overrides.json`）在模块加载时强制压过 env/.env，且前端模型列表硬编码过期预设，导致用户实际调用无凭证模型时出现"连接已中断"。
  - 后端 `GET /llm-config` 新增 `override_active` / `override_fields` / `models[]`（按 key/代理/本地运行时逐项判定可用性）
  - 后端 `PUT /llm-config` 对无凭证模型返回 422 并明示原因，从源头拦截
  - 前端聊天页模型选择器动态化：不可用模型禁用并标红"未配置"；切换失败回滚且展示后端原因
  - 前端设置页：覆盖生效时显示琥珀色警示条
  - 文档 `ENVIRONMENT_BASELINE_V1.md` 附录明确四级配置优先级
