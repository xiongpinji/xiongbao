# G3-C1 HA / K8s 包

> 适用阶段：G3 企业级长期运营
>
> 用途：作为企业级长期运营阶段的第一个执行包，冻结 HA / 多实例 / K8s 方向的目标、边界与后续推进入口。

---

## 1. 目标

G3-C1 的目标是：

> **把 `xagent` 从“单机 / Compose 可发布”推进到“可面向企业长期运行的 HA / K8s 方向”时，先固定目标与边界，再决定具体实现。**

它不是立即完成 K8s 平台化，而是正式开启：
- 多实例验证
- HA 诉求确认
- K8s / secretRef / external secret manager 路线
- 长期运行环境的最小边界

---

## 2. 当前阶段定位

当前 G3 还没有展开完整执行任务。G3-C1 的作用是：

- 宣布企业级长期运营阶段已激活；
- 把 HA / K8s 方向确认为第一个执行包；
- 为后续可观测 / 审计 / 容量包提供前置结构。

---

## 3. 当前边界

### 已有基础
- `full` 模式发布 / 回滚 / 演练口径已形成
- 环境基线与 secret 基线已存在
- 正式商用 GA 的文档闭环已形成

### 仍未完成
- 多实例 HA 验证
- K8s / secretRef 平台化
- 多副本状态一致性验证
- 集群级变更窗口治理

---

## 4. 下一步入口

后续推进 G3-C1 时，优先应回答：

1. 是否以 K8s 作为主平台方向？
2. 当前 secret 注入从 env 过渡到 secretRef / external secret manager 的目标形态是什么？
3. API / worker / stateful 依赖在多实例下是否有一致性前提？
4. 什么叫“企业级长期运营”的最小 HA 通过标准？

---

## 5. 当前结论

G3-C1 的存在表示：

> **项目已经从正式商用 GA 推进到企业级长期运营阶段，并将 HA / K8s 方向作为第一个执行包。**
