# RELEASE NOTES — v1.1.3（2026-08-14）

> 补丁版本：修复长任务用户实测发现的两个缺陷（工作流画布执行 / 纯对话幻觉防护）。

## 修复

- **P1 工作流画布「执行」不可用**：`POST /workflows` 原本完全同步执行，含 LLM 步骤的工作流必然超过前端 axios 30s 默认超时，请求从未到达后端。
  - 后端新增 `run_async`：立即返回 running 视图，后台任务独立会话执行并落盘终态（失败亦记录）
  - 前端画布执行异步提交后立即跳转运行详情页（2.5s 轮询直至终态）
  - 实测：修复后画布执行 9 秒跳转、后台约 3 分钟跑至 completed
- **P2 纯对话幻觉防护**：Chat 页（tool_mode=none 设计契约）下，goal 含执行意图且全程未调用工具时，回答下方展示提示条，明示"未真实执行"，防止模型文字回答被误认为任务完成。

## 测试

- 后端 18/18（新增：异步立即返回 + 后台终态落盘）
- 前端 43/43（新增 4 项源码合同：异步提交 / run_async API / 意图标记 / 提示条渲染）
- CI：PR #19 全绿后合并（ebc688c）；过程中修复 mypy 赋值类型与新增 E501 各一
