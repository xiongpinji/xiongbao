# X-Agent v1.2.1 发布说明

> 发布日期：2026-09-05 · 上一版本：v1.2.0（同日）
> 本版主题：**P1 空响应修复（本地思考型模型三连根因）+ E2E spec 对齐 v1.2.0 + MCP num_ctx 配置红线默认化**

---

## 一、P1 修复：本地思考型模型（qwen3 系）空响应（用户实测撞出，探针实捕根因）

v1.2.0 全栈实测中，用户在 Chat 页发送「写一个专业的计算器」触发
`model_empty_response_after_retry`。三个叠加根因与对应修复：

| 根因（实测数据） | 修复 |
|---|---|
| 聊天路径 max_tokens=512 截在思考 token 内（计算器 goal：512 全 think→空；2048→正常出码 ct=1722） | 首调 512→2048，恢复 1024→3072；截断判定阈值同步 |
| 任务类型分类兜底=coding，纯问答被注入「优先使用 file_write」提示→qwen3 该形态零输出（ct=0 finish=stop，6/6 稳定复现） | 兜底改 chat；编码词典扩充（写一个/写个/代码/函数/脚本/code/script…） |
| MCP 满配（5 server/76 工具）首调 prompt≈6.9k tokens 超 8192 ctx 截断 | `r2.env.example` 默认 `XAGENT_LLM__OLLAMA_NUM_CTX=16384` + README 快速开始补行 |

影响面界定：云模型与简单问答路径在 v1.2.0 即正常；本修复覆盖
「本地小模型 + 编码/规划型意图」与「直连 API 默认模式」两个受损组合。

## 二、E2E spec 对齐 v1.2.0（自 7 月前端重构后首次随版）

- 导航断言：短剧工厂 → 目标看板（ZCode 风格导航）
- Chat：发送按钮 aria-label、消息渲染类 `prose-agent`、流式正文或「查看运行详情」容错断言
- 工作流：旧「创建并执行」→ 专业模式画布冒烟（工作流编排/执行/保存/节点面板）
- 短剧路由：改断言排除说明页（发布边界即合同）
- Run Console：标题与实时徽标同节点渲染的匹配修正
- 设置：分区导航（索引/知识库/模型）替代旧标题断言
- **实测：对 v1.2.0 容器栈 9/9 全绿（21.9s）**

## 三、测试

- 编排 43 项全过：新增「问答不误判 coding」「编码保留提示」2 项回归
- 预算断言 [512,1024]→[2048,3072]（test_orchestration / test_runtime_runs 两处）
- 质量基线指纹随行位移刷新（计数不变：E501=186/S=17+15/ASYNC=6）

## 四、升级与兼容

- 无数据库迁移变更；无新配置必填项（`XAGENT_LLM__OLLAMA_NUM_CTX` 仅 MCP 满配部署需要）
- 行为变化：直连 API 默认模式下纯问答目标不再注入编码提示（分类兜底 coding→chat）
