# 企业内部助手变体 · 对外口径页

> 面向企业职能/全员场景的表述规范。所有口径以
> `docs/COMMERCIAL_STATUS_SOURCE_OF_TRUTH.md`（SOT）为唯一事实源，本页不得与其冲突。

## 1. 可以这样说

- "企业内部 AI 助手：企业员工用现有 SSO 账号直接登录，无需单独开通账号。"
- "支持 OIDC 标准协议对接企业 IdP（full 模式默认 Keycloak，可接企业现有身份源）。"
- "内部知识库问答：文档上传（ingest）→ 语义检索（search），管理员可维护文档全生命周期。"
- "全量审计留痕 + 证据自动归档：保留期 enterprise 形态默认 365 天，可按合规要求加长。"
- "已达到 SOT 定义的正式商用可交付口径（G1/G2/G3 全闭环）。"

## 2. 不建议这样说（沿用 SOT §6.2）

- 不说"支持所有 IdP 开箱即用"——OIDC 标准协议范围内对接，非标 IdP 需评估；
- 不说"知识库检索零幻觉"——RAG 固有边界，演示用客户真实文档不承诺准确率指标；
- 不说"多机 HA 已验证"——共享状态与数据一致性为**同机两实例**实测；
- 不说"等保/合规已认证"——审计与保留期是能力项，合规认证是客户侧流程。

## 3. SOT 不可宣称项核对（建包日 2026-08-04）

| 不可宣称项 | 本变体口径处理 |
|---|---|
| 多机 HA / Redis 自身高可用 | 不提；被问及时答"同机两实例已实测，多机演练在路线图中" |
| L2 E2B 云沙箱 | 不提（无 key 未实测） |
| 非当前机器目标环境演练 | 不提；交付走试点包 Gate 流程 |
| lite 模式账号体系 | 本变体仅按 full/enterprise 模式交付，天然规避 |

## 4. 行业化文案槽位（客户落地时替换）

- 产品名：X-Agent 企业助手（可冠客户名）
- 预置知识库清单：客户制度文档目录（试点包进入条件中确认）
- 审计保留期：按客户合规要求填写（≥365 天）
