# X-Agent v1.3.0 发布说明

> 发布日期：2026-09-05 · 上一版本：v1.2.1（同日）
> 本版主题：**Chat 页智能体化——默认真实执行（工具调用/文件写入/执行时间线），从对话机器人升级为智能体交互（对标 Codex/Hermes 交互标准）**

---

## 一、背景：用户实测判定「只是对话机器人」

用户在浏览器实测后判定：Chat 页交互与在线聊天机器人无异，达不到 Codex/Hermes 的智能体标准。
代码事实核实：ChatPage 曾把 `tool_mode` 硬编码为 `"none"`（c91103f 设计契约）——工具链路、
执行时间线渲染（InlineToolSteps）、tool_call 事件收集等基础设施全部存在，但被这一个开关整体关闭。

浏览器实测复现（修复前）：发送「写一个 Python 脚本计算斐波那契数列」→ 模型把代码**说**出来，
界面自认「未调用任何工具，未真实创建/修改/运行任何文件」。

## 二、修复：智能体模式为默认

| 变更 | 说明 |
|---|---|
| **默认 tool_mode auto** | Chat 页发送即走完整编排：计划→真实调用工具（file_write/file_read 等）→ 验证→交付 |
| **模式切换器** | 输入区新增 ⚡智能体/💬纯对话 切换 pill（默认智能体）；纯对话为显式选择 |
| **noToolsHint 门控** | 「未调用工具」提示仅在纯对话模式下出现 |
| 契约测试反转 | 原「必须 tool_mode none」契约（2 项）→ 新「默认 auto+切换+门控」契约（5 项） |

- 模式切换实测：⚡智能体 → 💬纯对话 切换即时生效

## 四、E2E 与门禁

- E2E「对话运行 agent」新增智能体切换器断言
- 前端 54 项单测全过（含 5 项新契约）；typecheck/lint 0 error

## 五、升级与兼容

- 无数据库迁移；无新增必填配置
- 行为变化：Chat 页默认执行真实工具（容器/沙箱边界内）；需要纯文字对话时手动切换「纯对话」
- 后端无改动（全部能力 v1.2.1 已具备，本版为前端交互解锁）
